# UNSW-NB15 Benchmark Security Dataset (Australian Centre for Cyber Security)

## Overview
Created by the IXIA PerfectStorm tool at the Cyber Range Lab of UNSW Canberra.
Combines real modern normal network behaviors with 9 modern attack families:
- Fuzzers, Analysis, Backdoors, DoS, Exploits, Generic, Reconnaissance, Shellcode, Worms

## Schema
49 network flow metrics including TCP window sizes, jitter, interpacket intervals, TTLs, and attack classifications.
