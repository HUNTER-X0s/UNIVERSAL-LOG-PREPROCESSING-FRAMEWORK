# CICIDS 2017 Benchmark Dataset (UNB / Canadian Institute for Cybersecurity)

## Overview
The CICIDS2017 dataset is the industry gold standard for intrusion detection systems (IDS/IPS).
Generated using realistic background network traffic alongside contemporary cyber attacks:
- Brute Force (SSH, FTP)
- DoS / DDoS (Hulk, GoldenEye, Slowloris)
- Web Attacks (SQL Injection, XSS, Brute Force)
- Infiltration
- Botnet (Ares)
- PortScan

## Schema
Captured via CICFlowMeter with 80+ network statistical features.
Verified RFC 5737 de-identified addresses, labeled ground truth classes.
