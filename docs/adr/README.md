# ULPF Architecture Decision Records

The Phase 0 baseline contains exactly 16 decision records, ADR-001 through
ADR-016. Each records context, decision, alternatives, pros/cons, security and
operational implications, and consequences. ADR numbers are unique and must
never be reused.

The authoritative blockchain decision is
[ADR-016: No Blockchain for Evidence Integrity](ADR-016-no-blockchain-for-evidence-integrity.md).
