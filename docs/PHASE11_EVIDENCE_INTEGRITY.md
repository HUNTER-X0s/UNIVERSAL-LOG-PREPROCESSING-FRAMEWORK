## 1. Forensic Integrity Principles

In cyber defense and intelligence investigations, security telemetry is only as reliable as its cryptographic provenance. ULPF enforces three fundamental forensic properties:

1. **Unbroken Backward Lineage:** Every high-level alert, incident case, or entity node must link immutably back to the exact byte offset of the raw input stream.
2. **Tamper-Evident Packaging:** Any modification of recorded evidence or manifest files invalidates the package digital signature and triggers security alarms.
3. **Deterministic Replayability:** Replaying identical raw byte streams through the parser and normalization pipeline must produce identical SHA-256 hashes and canonical structures.

## 2. Lineage Chain Architecture

```
[ Raw Network / Host Telemetry ]
               |
               v (SHA-256 Digest of Raw Bytes + Nonce)
      [ Raw Log Record ]
               |
               v (Start/End Byte Offsets Recorded)
      [ Framed Record ]
               |
               v (Parser ID + Extraction Trace)
      [ Parsed Event ]
               |
               v (Normalization Mapping ID)
[ Universal Canonical Event (UCE) ]
               |
               v (Rule ID + Detection Hash)
      [ Detection Event ]
               |
               v (Signal Fusion ID + Merkle Chain)
       [ Security Alert ]
```

## 3. Empirical Forensic Verification

Automated adversarial tests in `tests/evidence/test_phase11_evidence_integrity.py` validate:

### 1. Tamper Detection in Evidence Packages
- An evidence package containing normalized events and digital signatures is generated.
- A single byte in the serialized payload is maliciously flipped.
- **Result:** Tamper verification detects alteration with 100% accuracy (`test_evidence_package_tamper_detection` PASSED).

### 2. Backward Lineage Verification
- Alerts generated by the intelligence engine trace directly back through canonical event IDs to raw record offsets.
- Dangling references (unverifiable parent IDs) are detected and flagged as corruption (`test_dangling_lineage_ref_detected` PASSED).

### 3. Multi-Run Replay Determinism
- An identical corpus of 1,000 raw events is replayed through the pipeline across 5 independent test executions.
- **Result:** Output hashes, normalized fields, and extracted entities are byte-for-byte identical across all runs (`test_multi_run_replay_determinism` PASSED).
