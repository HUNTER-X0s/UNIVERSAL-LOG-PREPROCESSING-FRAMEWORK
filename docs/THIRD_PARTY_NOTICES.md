# Third-Party Inventory and Notices

No third-party source code, binary, model, dataset, or production artifact is redistributed by this repository in Phase 1. The direct Python dependency inventory is declared in pyproject.toml and requirements.lock.

License names and attribution obligations must be collected from a controlled dependency/SBOM report before redistributing a container or offline bundle. This document intentionally does not invent license notices from package names or memory. The connected build process must retain that report with the released artifact.
